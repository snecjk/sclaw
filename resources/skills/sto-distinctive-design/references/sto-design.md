## 1 · 颜色 token

**品牌色**
| 角色 | 值 |
|---|---|
| 申通橙(第一品牌色,主操作/焦点) | `#FF6700`(hover `#FF852E` / active `#D24D00`),淡底 `#FFF3EB`/`#FFF9F5` |
| 辅助蓝(第二品牌色,图表对比/进度条第二色) | `#005BE5`(hover `#0047B2` / active `#00337F`),淡底 `#E5F0FF` |

> **链接 / 次操作 / 下载一律用申通橙 `#FF6700`(品牌交互色,owner 2026-06-18 定)**;辅助蓝退出链接角色,**只作图表对比系列 / 进度条第二色**(同页橙过多时的第二色、橙+蓝对比组合)。申通橙既是"数据强调的固定职位"(进度条填充 / 明细表关键指标列 / 卡片趋势 sparkline)、也是"可交互元素色"(链接/次操作/下载)——两者都是橙、统一,不冲突;要避免的仍是把橙撒在装饰条/随机边框/每列。

**功能色(语义层全部基于这四组,各带浅底 `-bg`)**
| 语义 | default | bg(浅底) |
|---|---|---|
| 普通信息 info | `#4760FE` | `#F0F4FF` |
| 成功 / 正向变好 success | `#00B54B` | `#E6FFEA` |
| 警告 warning | `#FAAD14` | `#FFFBE6` |
| 危险 / 负向变差 danger | `#FA3C3C` | `#FFF2F0` |

> 五态固定:`default` 可交互 / `hover` / `active` / `disabled` / `bg` 轻量背景。禁用 `default` 做背景、`bg` 做文字。

## 2 · 字体 / 字号

- 正文:`"PingFang SC","Source Han Sans SC","Microsoft YaHei",...`
- 纯数字(指标值/数量/百分比/时间戳/单号):`"DIN Alternate"`(skill 默认内联自托管 D-DIN,见 [base.md](base.md) 字体加载);句子里夹的数字不切换字体。
- 字重只三档 `400 / 500 / 600`,**默认全用 500**,别自行改 400/700;同行字重 ≤2。

**字号 9 档(默认字重 500)**
| 名 | 字号 / 行高 | 用途 |
|---|---|---|
| helper | 10 / 12 | 辅助、极小标注 |
| label | 12 / 14 | 标签、Tag、Badge |
| body-sm | 13 / 16 | 三级文本、表格次要 |
| body | 14 / 18 | 正文、表单项 |
| body-lg | 15 / 20 | 一级文本、重要正文 |
| heading-sm | 16 / 22 | 卡片标题 |
| heading | 18 / 24 | 页面主标题 |
| display | 24 / 28 | 指标卡数值、超大标题 |
| hero | 28 / 32 | Banner 主标、强调标题 |

> 数字两位小数 `18.88%` / 金额 `¥500.00`;中英/中数间加空格,符号与数字间不加(`62%`、`¥500`)。

## 3 · 圆角(四档严格对应,不混用)

`sm 4px` 标签/切换器内层 · `md 6px` 按钮/筛选/输入框 · `lg 8px` 小容器/Toast · `xl 12px` 大卡片/模态框/抽屉/页面级容器。报表主用 `12px`。记忆:按钮 < 小容器 < 大卡片 < 模态框。

## 4 · 间距(两层,不跨层用)

- **页面级 10px**:页面边缘、卡片之间、通栏之间。
- **组件级**:卡内 padding 12 · 模块间 12 · 模块内 padding 8 · 元素间 8 · 头部左(图标↔标题)4 · 头部右(按钮组)8。
- **禁规范外间距**(5/15/20/24 等)。
> skill 数据报告/看板按 [density.md](density.md) 进一步收紧(body padding 16、分节 16/8、卡间 gap 12、表行 ≤3),固定 px、禁 clamp。

## 5 · 颜色语义应用(母版 Part 4 · 红负绿正)

**三条基本原则**
1. 靠色块面积控强度:面积小 = 降噪版(仅文字/淡底),面积大 = 强化版(整格/整卡填色)。**默认降噪,强化只留单个异常主角。**
2. 红 = 负向变差,绿 = 正向变好。
3. **业务取向:强化负向 + 降噪正向。** 非必要不用绿色色块卡;一页里红比绿显眼是对的。

**指标卡**:主数据正负 → 文字染色(负红/正绿);想突出某卡 → 整卡淡底(`danger-bg`/`success-bg`)。方向看"变化对业务的好坏"不看数值大小(单票成本↑=负,装载率↑=正)。可点击/可下钻数值 **用下划线**,不用高亮色冒充可点击。

**表格**:单格降噪上色(文字/淡底);整格填满 = 强化,慎用。可视化列背景条**按方向配色**(越大越好→绿条,越大越坏→红条)。区分列组改**表头底色**,不给数据格乱铺色。双色阶分级:正向走绿阶、负向走红阶,权重高的列优先排优先上色阶。

**消息提示**:普通=蓝 info / 成功=绿 / 警告=黄 / 错误=红(蓝在此为合法功能色)。

**标签流程色**:灰(未开始/失效)→ 蓝(进行中)→ 绿(成功/完成)→ 橙(即将过期)→ 红(失败)。浅底 `-bg` + 同相深字胶囊,圆角 `sm`。

**排行榜 · 排名 vs 序号**:排名(表名次,要突出)前 3 奖牌/底色,两端用正负向色(前绿末红),整榜 ≤ TOP10;序号(仅行号)用普通正文,不加奖牌不染色。红黑榜并排不互套带边框大容器(防框中框)。

## 6 · 生成约束(母版 Part 5)

颜色全用 CSS 变量、禁写死 hex;主操作/次操作/链接/下载橙(辅助蓝仅图表对比/进度条第二色);文字只 text-*、背景只 fill-*、描边只 outline-*;hover/active/disabled 用同色系 token。字号与行高成对取变量。字重默认 500。
