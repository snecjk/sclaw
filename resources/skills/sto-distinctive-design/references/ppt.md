# PPT 模式 —— 用户要求"生成 PPT"时的汇报逻辑与页间承载

> 触发:用户明确说"生成 PPT / 做成幻灯片 / 汇报演示 / 一页一页讲"。不触发时仍按默认数据报告(满宽长滚动)处理。
> 本文只加"按汇报逻辑分页 + 页间如何承接"这一层;**单页内部的版式仍遵守全部地板与硬规格**(框中框、表头列对齐、卡片白名单(全页≤2卡位)、行高收窄、禁高饱和卡、数字列右对齐加粗——一条不豁免)。

---

## 1. 先定汇报逻辑(分页的依据,不是把长报告切片)
PPT 不是"把滚动报告按高度切成几屏",而是**按一条汇报叙事线分页**。默认叙事骨架(按内容裁,不照搬):
```
封面 / 标题页      —— 主题 + 周期 + 一句话核心结论(整份的 takeaway)
→ 大局页(结论先行) —— 3 秒读懂的总判断 + 最关键的 2-3 个数
→ 分项页(每页一论点)—— 业务量 / 成本 / 时效… 一项一页,每页只讲清一件事
→ 异常 / 风险页     —— 如有,单独一页如实陈列(不藏在分项里)
→ 结论 / 行动页     —— 回扣大局,给下一步
```
- **一页一个核心论点**(one idea per slide):一页只回答一个问题,别把三个分项塞一页。
- **页标题就是该页的论点句**,不是栏目名:写"成本环比降 4.2%,主因 X"而非"成本数据"。

## 2. 页与页之间怎么承接(单页间内容承载)
单页不是孤岛,相邻页要有逻辑递进,读者翻页时跟得上:
- **总—分—总闭环**:大局页抛出的判断,分项页逐页给证据,结论页收回来。分项页的标题论点应能"挂回"大局页的总判断。
- **承上启下线索**:同一指标跨页出现时口径/命名一致(别这页叫"揽收量"下页叫"业务量");可在页脚用极小字给一条"3/7"页码 + 章节名,让位置感连续。
- **不重复**:大局页已放大的关键数,分项页给的是它的拆解/归因/趋势,不是原样再贴一遍(沿用"同一数据 ≤2 次、跨层"地板)。
- **节奏**:封面/大局/结论页相对"透"(留白多、字大、少元素),分项页相对"密"(表/图承证据)——疏密交替,别每页一样满。

## 3. 单页版式约束(PPT 专属)
- **按页(slide)切分容器**:每页一个全屏 section(如 `16:9`,`aspect-ratio:16/9` 或固定 `1280×720`),页间分隔清晰;**页内不再套大边框容器**(框中框照禁)。
- **单页信息量克制**:一页 1 个核心图/表 + ≤6 个支撑数据点;塞不下就拆成两页,别硬挤(与默认报告"曝光率优先塞满"取向不同——PPT 是"一页一论点、可呼吸")。
- **页内仍守硬规格**:数字列右对齐加粗、表头与列同列对齐、卡片白名单(全页≤2卡位)、禁高饱和卡、行高收窄。
- **导出友好**:若需逐页截图/导出,每页可独立成屏、`page-break` 干净;动效降级为页内入场,不做跨页滚动联动。

## 可检验失败定义
- **①把长滚动报告按高度切片当 PPT(页与页无叙事递进、页标题是栏目名而非论点)= 违规;②一页塞多个不相干论点 = 违规;③同一关键数在大局页和分项页原样重复(未做拆解/未跨层)= 违规;④单页内仍出现框中框/高饱和卡/表头列错位 = 违规(页内硬规格不豁免)。**
