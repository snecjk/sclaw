# Layout —— tab 嵌套 & 单卡片 / 多卡片页面布局规则

> 来源：未命名文件夹2（卡片级tab / 抽屉级tab / 弹窗级tab / 单卡片页面布局 / 堆叠（多卡片）卡片页面布局 / 单卡片&堆叠卡片页面布局）。
> 这些是**组合规则**，不是原子组件——原子组件（选项卡 Tabs / 分段切换器 / 卡片 / 弹窗 / 抽屉）见 [sto-app.html](sto-app.html) 与 sto-components.html。本文件只回答「多个 tab 叠在一起、卡片怎么排」。

---

## 0 · 间距铁律（一层一层往下拆）

- **大卡片四周 = 16px**；卡片里面的模块、模块内的内容 = **12px**。
- 卡片容器之间（多卡片堆叠）= **12px**（与 density.md 容器间距一致）。
- tab 与紧贴的卡片容器**形成整体**：tab 紧挨卡片上沿，不留额外空隙。

---

## 1 · 两种 tab 形态怎么选（最关键的一条）

| 形态 | class | 何时用 |
|---|---|---|
| **分段切换器**（内容切换器，胶囊）| `.sto-seg` | 对不同**维度**的切换、或切换内容少、结构一致时（**默认用这种**）|
| **下划线文字 tab** | `.sto-tabs` | 切换内容**多且变化大**、含多个子模块、分段切换器「压不住」下面内容时 |

> 判断口诀：**「压得住」用分段切换器，「压不住」用下划线 tab。** 一个 tab 切换后下面只是换组数据 = 压得住；切换后整块版面结构都变、带多个子模块 = 压不住。

## 2 · 卡片级 tab（卡片内部的 tab）

- **一层卡片 tab**：维度切换/内容少 → 分段切换器；内容多变化大 → 下划线 tab。
- **两层卡片 tab**：第一层用下划线 tab，第二层用分段切换器（或反之，外层「压不住」的那层用下划线）。
- **三层卡片 tab**：外层下划线 tab → 中层下划线/分段 → 最内层分段切换器。一层层往下拆，**层级越深、形态越轻**。
- 配合「有无页面级选项卡」：卡片上方若已有页面级 tab，卡片内 tab 顺势降一档形态，避免两个下划线 tab 撞在一起分不清主次。

## 3 · 弹窗级 / 抽屉级 tab

- **一层 tab**：紧贴弹窗/抽屉标题下方，通栏下划线 tab。
- **两层 tab**：第一层下划线 tab（内容多且复杂）+ 第二层分段切换器（内容较少且单一）。
- **三层 tab**（抽屉，纵深大时才用）：下划线 → 下划线 → 分段，逐层变轻。
- 弹窗/抽屉里 tab 同样紧贴容器、内 padding 16px；头部/底部操作固定，tab 与内容一起滚动。

## 4 · 单卡片 vs 多卡片页面布局

### 何时单卡片、何时多卡片
- **单卡片**：一个页面就是一张大卡片，内部靠 tab / 模块切换。适合内容同属一个主题、切换层级 ≤ 2。
- **多卡片（堆叠）**：页面是若干并列/堆叠的白底卡片。适合页面承载多个相对独立的模块。
- **拆分信号**：当单卡片里 tab 嵌套层级太多（页面级两层 + 卡片内还有两层），意味着信息切换层级过载 → **拆成多卡片布局**，每个模块独立成卡。

### 页面级 tab（最外层）
- **一层页面级 tab**：tab 通栏在最上，下方是单卡片或多卡片内容。tab 上方若还有内容，用**非通栏**的默认选项卡。
- **两层页面级 tab**：第一层 + 第二层都在页面顶部，下方再接卡片（卡片内可再有自己的 tab）。
- **一层 / 两层混合**：某些一级 tab 下有二级 tab、某些没有——本质是上面两种情况相结合，按当前一级 tab 是否需要二级动态显示。

### 组合速查
| 页面布局 | 页面级 tab | 卡片内 tab | 处理 |
|---|---|---|---|
| 单卡片 | 一层 | 无 | 一张大卡，顶部一层 tab |
| 单卡片 | 一层 | 一层 | 卡内模块再带分段/下划线 tab，注意主次 |
| 单卡片 | 一层 | 两层 | 信息层级偏多，可考虑拆多卡片 |
| 多卡片 | 一层 | 某卡有 tab | 各卡独立，带 tab 的卡自带分段切换器 |
| 多卡片 | 两层 + 全局筛选栏 | — | 顶部两层 tab + 全局筛选栏，下方堆叠卡片 |
| 单卡片&多卡片混合 | 一层/两层 | — | tab1 下是单卡片、tab2 下是多卡片，按内容定 |

## 5 · 与通知/筛选的协同（来自 通知公告.pdf / 各布局）

- **全局筛选栏**：多卡片布局时可作为独立的一张卡片置于顶部；单卡片时放卡片内顶部。
- **通知公告（Alert）**：位于卡片容器内时距相关内容 12px；多卡片时可单独成卡、必要时吸顶；和 tabs 结合——针对所有 tab 的提示放 tab 上方，只针对某个 tab 的放该 tab 内容区上方。
- **弹窗/抽屉顶部提示**：用 Alert/文字提示紧贴标题下、与内容形成整体（见 sto-app.html #5/#8/#9）。
