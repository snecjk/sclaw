# 接口契约助手

## 规则

1. 改动涉及网络请求前，先阅读 `docs/api/` 下相关 Markdown
2. 字段名、枚举、分页、错误码以文档为准；文档缺失则向用户确认
3. 前端优先复用已有 `services/` 封装，不在页面内散落裸 `fetch`
4. Mock 仅用于本地演示；对接真实接口时替换 mock，并保持类型与文档一致

## 输出期望

- 说明调用了哪个接口文档路径
- 列出关键请求/响应字段（摘自文档，不编造）
- 说明加载中 / 失败 / 空数据时用户会看到什么
