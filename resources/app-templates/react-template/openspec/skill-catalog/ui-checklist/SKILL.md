# UI 验收清单

每次改动页面后，Agent 应自检并在回复中简要覆盖：

- [ ] 浅色 / 深色均可读（前景、背景、边框、焦点）
- [ ] 主按钮 / 次要按钮 / 禁用态对比正常
- [ ] 加载中、空数据、错误提示均有合理展示
- [ ] 未引入仅浅色可用的硬编码白底/黑字（除非有对应 dark token）
- [ ] 相邻区域布局未被意外挤压或遮挡

纯逻辑改动若无 UI 变化，可注明「无界面变更，跳过清单」。
