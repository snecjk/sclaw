# 层壳

换皮只改产品名与侧栏树，不改这套尺寸。

## 结构

稿宽 **1440**。顶栏 60 + 系统页签 28 + 侧栏 180 + 主区 1260 灰底。

```
┌──────────────────────────────────────────── 1440 ─┐
│ Topbar 60                                         │
├───────────────────────────────────────────────────┤
│ OpenTabs 28                                       │
├─────────┬─────────────────────────────────────────┤
│ Sidebar │ Main  pad 16                            │
│  180    │  灰底 #F0F2F5 · 内容落白卡              │
└─────────┴─────────────────────────────────────────┘
```

屏宽 ≤1280 默认收侧栏；用户手动展开则保持，直到再次跨临界或刷新。

## 顶栏

- 高 **60**，左右边距 **16**
- 品牌标：整份内联 [`assets/sto-mark.svg`](assets/sto-mark.svg)，`fill=currentColor` → `--accent`。展示 **68×26**，`viewBox="0 0 67.81 26"`。三笔都要：S 左、T 中、O 右圆（`fill-rule: evenodd`）。禁止当 `<img>`（会变黑）；禁止只抄 S/T；禁止盒子小于 68（会裁掉 O）；禁止写成橙色文字「STO / sto」
- 产品名：标右侧，普惠体 26 Bold / lh26，色 `--fg`；无字体文件回退苹方。换业务只改这一行字，不改 STO 图形
- L1：16px Medium，项间距 8，水平 padding 12，不换行
- 搜索、快捷入口默认不画

换业务只改名，不改 STO 图形。

## 系统页签

壳顶部多开，不是页内业务 Tab（页内 → [`tabs.md`](tabs.md)）。

**必须从 [`reference.html`](reference.html) 拷 `.sto-opentabs` 整段**（栏、签、`.sto-opentab-bg` 里的 SVG、关闭钮、以及对应 CSS）。只改文案和开了几张。不要自己画圆角条或倒三角。

**同时只能有一个选中。** 打开的页 ≠ 选中。交互 → 下面「点击」。

### 对 / 错

| | 脸 |
|--|-----|
| **对** | 未选浅灰底 `#F5F6F7` + 灰字 `#4E5969`；选中橙底 `#FF6700` + 白字；底是一张文件夹 SVG，**右下**伸出台阶（不是底边正中倒三角） |
| **错** | 两个都橙；未选也白字；圆角矩形；`::after` 倒三角 / 气泡尾巴；圆角条再拼钩子 |

### 色（锁死）

| 状态 | 底 | 字 |
|------|----|----|
| 未选 | `--th` `#F5F6F7` | `--fg-2` `#4E5969` |
| 选中 | `--accent` `#FF6700` | 白 `#FFFFFF` |

禁止：深灰 / 炭黑 / `--fg` 当页签底；未选白字；两个同时橙或两个同时深。

### 结构（与 reference 相同）

每个签：文字叠在 SVG 上。SVG 绝对定位铺满，`fill=currentColor`，`preserveAspectRatio="none"`。列表 `flex` **gap = 0**。容器不要 `border-radius`、不要描边、不要 `::before/::after` 三角。

```
.sto-opentab                高 24 · 宽 125（首页 52）
├── .sto-opentab-bg svg     inset 0 · 未选 color --th · 选中 --accent
├── .sto-opentab-label      12px
└── .sto-opentab-close      非首页 · 12× 线型 ×
```

path 用 [`assets/opentab-home.svg`](assets/opentab-home.svg) / [`assets/opentab.svg`](assets/opentab.svg)，不要改。

| 项 | 值 |
|----|-----|
| 栏高 / 签高 | 28 / **24**，底对齐 |
| 首页 | 宽 **52** · 无关闭 · `opentab-home.svg` |
| 其他页 | 宽 **125** · 左 pad 12、右 pad 28 给 × · `opentab.svg` |

禁止：圆角色块贴死；下划线 Tab 冒充系统页签；首页加 ×。

## 侧栏

- 宽 **180**
- 模块标题 40 → 二级 40（可展开）→ 三级 36
- 选中三级：橙字 + `--surface-warm` 底
- 有二级时展开组互斥

不要做成扁平列表、右侧橙竖线、右缘半圆手柄。

## 点击

实样 → [`reference.html`](reference.html)。页内 Tab 点击 → [`tabs.md`](tabs.md)。

页签是侧栏**叶子**的多开，文案一致。首页除外（无对应叶子）。不要放侧栏里没有的页签。同时只有一个页签选中；打开 ≠ 选中。同一叶子不重复开第二个签。

| 点什么 | 结果 |
|--------|------|
| **三级叶子** | 已有页签 → 选中该签；没有 → 新增。主区切到该页。该叶子高亮；其二级展开，其他组收起 |
| **二级** | 只展开/收起本组（组互斥）。**不开**页签、不切主区 |
| **模块标题** | 无操作 |
| **页签**（点文字，不是 ×） | 选中该签，主区切对应页。有叶子则高亮并展开其二级。点首页：三级取消高亮，二级保持原样 |
| **页签 ×** | 首页不可关。关掉的是当前签 → 先切右侧邻签，没有则左侧，再没有则首页；侧栏跟新选中页走。关掉的不是当前签 → 只去掉该签，选中和侧栏不变 |
| **顶栏 L1** | 切一级模块、换侧栏树。不当页签用 |

选中页签/叶子后，主区必须换成该页内容，不要只改高亮。

## 主区

灰底 + 白卡槽。摆卡方式 → [`layouts.md`](layouts.md)。

- padding **16**
- 内容（含空态）落在白卡上
- 面包屑时机 → [`page-head.md`](page-head.md)
