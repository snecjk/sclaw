# 生产页面内容

卡内列表、表格、指标、状态、语义色。壳、白卡容器、页签、面包屑仍走 [`SKILL.md`](SKILL.md) / [`layouts.md`](layouts.md) / [`tabs.md`](tabs.md) / [`page-head.md`](page-head.md)。

本文件从设计师 HTML 报告规范抽出，**改写成可发布的业务页**。

## 这不是报告 HTML

⛔ 禁止把建站页做成聊天交付物：

- 不要 `build.py` / `lint.py` / `<!-- STO:BASE -->` / `<!-- STO:DAILY -->` / `<!--t:main`
- 不要日报类名 `.mc` `.masthead` `.kf-grid` `.diag` `.mod`（那是独立 HTML 的短名）
- 不要钉钉无 JS 直出、不要宽表转 `<details>` 卡片
- 不要页尾 `Designed by STO Design`
- 不要满宽出血、不要 12px 正文日报密度

产物是 **React + antd** 或 **A2UI antd Catalog**，样式只写 `src/theme/theme.css` 的 `--sto-*`（及 shadcn 别名）。本文 hex 只作对照，落盘必须 `var(--sto-…)`。缺 token 先补进 `theme.css`，再在页面引用。

| 本文件说法 | 落盘用 |
|---|---|
| 页底 / 白卡 | `--sto-color-bg-layout` / `--sto-color-bg-container` |
| 主/次文字 | `--sto-color-text` / `--sto-color-text-secondary` |
| 描边 / 浅分割 | `--sto-color-border` / `--sto-color-border-secondary` |
| 品牌橙 | `--sto-color-primary`（hover `--sto-color-primary-hover`） |
| 成功 / 警告 / 危险 / 信息 | `--sto-color-success` / `--sto-color-warning` / `--sto-color-error` / `--sto-color-info` |
| 间距 4…32 | `--sto-space-1` … `--sto-space-8` |
| 圆角 6 / 8 / 12 | `--sto-radius-md` / `--sto-radius-lg` / `--sto-radius-panel` |

弱文字 `#86909C`、表头底 `#F5F6F7`、斑马 `#FAFBFC`、语义浅底：[`tokens.css`](tokens.css) 有，`theme.css` 没有就先加 `--sto-color-text-muted` / `--sto-color-th` / `--sto-color-zebra` / `--sto-color-*-soft`，禁止页面写死 hex。

## 先定页面类型

| 类型 | 结构 | 不要 |
|---|---|---|
| **查询列表**（默认业务页） | 一张工作卡：筛选 + 表 + 分页。壳已标明当前页，卡头不要橙条页名 | 再套一层居中 1120 营销壳；不要「结论先行」日报头 |
| **新建 / 编辑 / 详情** | 面包屑在卡外；卡内按分区用橙条标题，**一卡一根** | 把侧栏路径再抄成大标题 |
| **看板 / KPI** | 多张白卡；每卡说明本模块。指标卡 1 主 + N 副 | 全页只许 2 个卡位（那是报告铁律，工作台不套） |
| **营销落地** | 才仿 `HomePage`：1120 居中、section 大间距 | 把列表/表单做成卖点三列 |

查询 + 表 + 分页：A2UI 用 `AntdFilterBar` + `AntdTable` + `AntdPagination`；JSX 用 antd 同名组件。参考 `src/pages/customer-list.page.json`。

## 颜色怎么用

橙是**品牌交互色**，不是装饰色。

- 主按钮、链接、选中、进度条填充、图表第一系列 → 橙
- **表内不用橙**：关键列黑加粗，数字只用语义色
- 红 = 负向变差，绿 = 正向变好（看业务极性：成本↑是红，揽收↑是绿）
- 状态默认降噪：文字或小胶囊；整卡淡红底只留给**一个**异常主角
- 进度条填充是分类色（橙；第二系列用 `--sto-color-info`），**不要按达标/未达把条染绿/红**；好坏写在数值或药丸上
- 图表对比第二色可用 `#005BE5`，但先把它写进 `theme.css`（如 `--sto-color-chart-2`），**不作链接色**

⛔ 冷蓝/靛蓝渐变 banner、`#1677ff` antd 默认蓝当主色、每卡不同色顶边、框中框、Inter/Roboto 当中文主字体。

抽成灰度后，层级还要靠字号/字重/留白成立。散了 = 在用颜色遮结构。

## 指标卡

每张卡固定三段，禁止空心「大数 + 名字」：

```
名称（小、次文字）
主值（卡内最大，28px / 600，唯一主角）
副指标 0–4 个，每个必须带对比维度（环比 / 目标 / 对标）
```

- 标签在上、数值紧贴正下，不要左右甩到两端
- 状态药丸小于主值，不要做成顶部大彩条盖过数字
- ≤6 张 → 列数 = 卡数；7–8 → 4 列；桌面不要写死 2–3 列
- 口径/备注留在主值下小字，不要可视化时丢掉
- 缺数写 `—` 或「暂无数据」，**禁止补 0**

## 表格

用 antd `Table`，不要手写日报 `<table class="main">`。

- 金额 / 数量 / 率 / 涨跌：**右对齐** + `tabular-nums`
- 名称 / 状态：左对齐；序号列窄
- 斑马只染偶数行；表头用浅底，不要和斑马糊成一块
- 缺单元格显式 `—`，不要空白、不要删列
- 超长文本截断 + `title`，禁止撑破列
- 加载、空、失败都要画：空用 `Empty`，失败说「什么失败 + 能做什么」

## 状态五件套

每个表 / 卡 / 图都要想过，不要只画「数据齐全」：

| 态 | 做法 |
|---|---|
| 齐全 | 正常 |
| 空 | 诚实空态，不编造 |
| 异常 | 原值 + 语义色 + 小标签；不替用户下「严重」结论 |
| 极端 | 长名、大数、千行不崩 |
| 加载 / 失败 | 骨架或 Spin；失败可操作 |

异常要颜色 + 形态双编码（红 + ▼ / 药丸），不要只靠颜色。

## 密度（工作台，不是营销页）

主区 pad **16**、白卡 pad **16**、卡缝 **16**、卡内模块缝 **12**、控件高 **28**。见 [`layouts.md`](layouts.md)。

- 工作台页：**不要** `max-width: 1120px` 居中，主区随壳
- 营销页：才用 `.home-baseline` 的 1120 / 大间距
- 间距只用 `--sto-space-*`，不要 `clamp()` 当日常 padding
