# 面包屑与标题时机

主区页头只做两件事：要不要面包屑、卡上要不要橙条标题。侧栏和顶栏 L1 已经标明当前页，不要再复制成大标题。

实样：[`reference.html`](reference.html) 上半是一级列表（无面包屑、列表卡无橙条页名）；其下「下钻主区」才有面包屑 + 分区标题。

## 面包屑

组件名 **PC-8.面包屑**。在**白卡外**独占一行，与卡间距 **12**。横排、垂直居中、项间距 **8**。不要用 `/`、`>` 字符，不要做成链接胶囊、下划线或带底色块。

稿：MasterGo `PC-8.面包屑` 类型=默认。

| 部位 | 规格 |
|------|------|
| 祖先 | `--fg-2` `#4E5969` · PingFang SC · **14** / 行高 **18** · LinkButton secondary 小号 |
| 分隔 | 16×16 右箭头 [`assets/breadcrumb-sep.svg`](assets/breadcrumb-sep.svg)，`fill=currentColor` → `#4E5969`（当前项前的箭头稿上是 `#1D2129`） |
| 当前项 | `--fg` `#1D2129` · **14 Medium** / 行高 **18** · 不可点 |

祖先可点回上一级。不要当页主标题。不要放进系统页签栏。分隔不要写成 `>` 或 `/`。

| 页面 | 要不要 |
|------|--------|
| 一级列表 / 看板 / 查询首页 | **不要**。侧栏已定位，禁止「有表就加」 |
| 详情 / 新建 / 编辑 / 流程 / 下钻子列表 | **要**。至少两级：来源页 / 当前页 |

路径跟侧栏或来源页走，例如 `运单查询 → 新建运单`。不要写成把 L1 再抄一遍。

## 标题出现时机

橙条（3×14）+ 间距 8 + 14 Medium 是**分区标题**，不是页名。

| 场景 | 卡头橙条标题 |
|------|----------------|
| 一级列表工作卡（筛/表，壳已显示当前页） | **不要**。不要写「工作卡」当页名 |
| 表单 / 详情的分区（基本信息、收件人） | **要**。一卡一个一级标题，不要两根橙条 |
| 多卡看板 / 弱相关模块 | **要**。每张卡说明本模块是什么 |
| 二级 / 三级小节 | 要字，**不要**再画橙条 |
| 贴顶的一级选项卡 | Tab 本身就是切换标题，卡内不要再套同名橙条 |

业务主标题全页只出现一次。页级「新建 / 导出」放卡外或表工具栏，不要放进标题行当实心主按钮。
