# 主区与卡片容器

主区在灰底上摆白卡。卡内组件自写。

## 主区

- padding **16**
- 内容落在白卡里；空态也进白卡
- 面包屑、橙条标题何时出现 → [`page-head.md`](page-head.md)
- 单卡可充满主区；多卡堆叠不必撑满
- 弱相关分卡；强相关可同卡

| 排布 | 何时 |
|------|------|
| **堆叠** | 默认，白卡从上到下 |
| **左辅右主** | 左树 / 锚点 + 右内容卡 |
| **分栏** | 一行多卡；24 栅，gutter **12**；常用 span 24 / 12 / 8 / 6 / 4 |

span 之和 ≤24，或允许折行。不要 5 列不等分。

## 卡片容器

```
Card                         白底 · 圆角 8 · pad 16
├── Header（可全空）         左：标题/注释/切换器 · 右：操作/筛选
└── Body                     与标题间距 12 · 大模块缝 16 · 子元素缝 12
```

| 用途 | 值 |
|------|-----|
| 主区内边距 | 16 |
| 白卡纵缝 | 16 |
| 卡内边距 | 16 |
| 卡内大模块之间 | 16 |
| 并排卡缝 / 栅格 gutter | 12 |
| 模块内子元素 | 12 |
| 橙条 ↔ 标题 | 8 |
| 标题 ↔ 右侧功能 | 8 |
| 标题 ↔ 下方内容 | 12 |
| 白卡 / 嵌套小卡圆角 | 8 |

一级选项卡可紧挨卡片上沿；卡内仍 16 内边距。贴顶时去掉卡片上圆角。脸、层级、点击 → [`tabs.md`](tabs.md)。

### 卡头

默认至多一个一级标题。何时画橙条 → [`page-head.md`](page-head.md)。

- 一级标题：左侧橙装饰条（3×14）+ 文案间距 8 + 14 Medium
- 右侧：次要按钮、筛选、切换、查看更多、普通文本。不要放实心主按钮
- 左：注释、切换器；右：按钮、快捷筛选。只有右侧时，左侧加标题

可选：描述、标签、帮助。可编辑：修改 → 确定/取消。大卡可收起。

### 自适应

固定高、宽随主区最常用。图片列表可用等比缩放。
