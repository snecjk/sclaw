# 选项卡

页内切换内容，不是锚点，也不是壳上的系统页签（文件夹轮廓 → [`shell.md`](shell.md)）。

点击当前项切下方内容；无分类不要硬加。最多三级，语义必须不同。

## 选型

| 你要… | 用 | 脸 |
|--------|-----|-----|
| 业务阶段 / 整块内容切换 | **一级** | 高 **40** · 橙字 + 底边橙下划线 · 项左右 pad 16 |
| 同块内的维度 / 口径 / 结果分类 | **二级** | 高 **28** · 项间距 **24** · 选中橙字，无下划线底栏 |
| 模块内少选项（日周月、卡头切换） | **内容切换器** | 高 28 · 连体描边 · 选中橙边 + `--surface-warm`。**不是** Tab |
| 浏览器多开 | 系统页签 | 壳层文件夹 SVG，禁止圆角色块并排 |

一级贴卡顶时：Tab 条与卡上沿齐平，去掉卡片上圆角；卡内仍 **16**。不贴顶时，Tab 距下一块 **16**，不要贴死。

跟卡边左右对齐 **16**。

## 嵌套

一级（域/阶段）→ 二级（口径）→ 切换器（少选项）。禁止四级。禁止一级和卡头切换器用同一组阶段名。

步骤条用来分步填表，不要和 Tab 互冒。

## 交互

- 点击项：该项选中，对应内容显示，其余内容隐藏
- 当前项可辨：一级靠橙下划线，不要只靠颜色
- 系统页签点选中、点 × 关闭的完整契约 → [`shell.md`](shell.md)「点击」。不要用系统页签切卡内 panel
