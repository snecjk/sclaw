管什么

前端工程源码、A2UI 页面描述（page.json）、模板锁定壳与依赖清单。

云端仓库是权威来源：换机、误删都能克隆恢复，不丢工作成果。

怎么管

每轮对话 / 保存触发静默同步；提交前自动拉取，冲突先交给 AI。

用户可选「保留我的 / 用云端的」；无需理解 commit、branch、rebase。

用户不碰什么

不碰 Node / npm / Git 命令行，不碰冲突解决界面。

凭证一次粘贴后长期托管——代码管理对用户完全透明。

价值：代码始终有仓、有快照、可恢复 —— 为 A2UI 生成与低成本发布提供稳定底座。

04 · 如何使用公司接口
用户怎么用接口：自然语言/指定 CLI，AI 接进页面
用户只说业务需求，指定一条公司 CLI 指令即可在页面中使用对应接口
① 说需求「查本月结算数据」
→
② 指定 CLI选一条 sai-cli 指令
→
③ AI 读 help参数 / 字段 / 地址
→
④ 接进页面action 契约取数
→
⑤ 渲染预览表格 / 筛选出数

用户怎么做

用自然语言描述页面；需要数据时，指定要用的 sai-cli 指令（或从候选列表里选一条）。

说不清命令名时，可让 AI 用 discover 搜候选，仍由用户确认指定。

系统怎么接

AI 执行 help 拿到参数与返回字段，注册开发代理，写入 action 契约。

页面只认契约（actionId），不写死接口地址；权限与审计沿用 CLI 既有体系。

扩展新接口

总部新增业务能力 = 发一条 CLI 命令 + 技能说明，客户端零改动即时可用。

用户指定新指令后，AI 即可按同样链路接到页面上。

05 · 低成本发布
低成本发布：推送 Git 即上线，静态托管零常驻成本
用户点「保存并发布」之后
自动提交 → 推送代码仓库 → DevOps 构建 → 静态部署上线 → 分配域名可访问
构建产物与发布平台约定完全一致（npm run build → build/），前端应用零适配进流水线；静态托管无常驻服务，成本极低。
SClaw 侧：管好代码与发布体验

状态可视化：创建迭代 → 同步代码 → 流水线构建 → 成功 / 失败，全程可见。

失败自愈：失败信息自动回流 AI 诊断修复，用户只看到「发布中 / 发布成功」。

冲突兜底：提交前自动拉取，冲突先由 AI 处理。

为什么成本低

静态托管：前端产物托管访问，无需常驻后端服务与服务器租金。

推送即交付：SClaw 把代码推到 Git，部署与域名由平台完成。

零适配：构建约定对齐发布平台，应用直接进流水线。
