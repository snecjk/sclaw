# STO-CLAW 系统架构图

## 1. 系统整体架构
```
用户 → Electron桌面应用 → 渲染进程(React UI) ←→ 主进程(Node.js) → AI提供商API
```

## 2. 应用内部架构
```
渲染进程(React) ← IPC → 主进程(Electron) ← HTTP → 外部API
```

## 3. 技术栈
| 层级 | 技术 | 说明 |
|------|------|------|
| 框架 | Electron | 桌面应用 |
| UI | React + TypeScript | 前端 |
| 构建 | Vite | 打包 |
| 样式 | TailwindCSS | 样式 |
| 状态管理 | Zustand/Redux | 状态 |
| 打包 | electron-builder | 发布 |

## 4. 部署架构
- 支持 macOS/Windows/Linux
- 支持 x64/arm64
- 自动更新
