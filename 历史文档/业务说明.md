# STO-CLAW 业务说明

## 1. 业务领域
StoClaw 是基于 OpenClaw 的图形化 AI 助手桌面客户端,为用户提供跨平台的 AI 交互体验。

## 2. 核心业务实体

### 2.1 AI 提供商(Provider)
| 实体 | 说明 |
|------|------|
| OpenAI | OpenAI API(GPT系列) |
| Moonshot | 月之暗面 Kimi |
| Anthropic | Claude API |

### 2.2 技能(Skill)
| 实体 | 说明 |
|------|------|
| 预装技能 | 内置常用技能包 |
| 自定义技能 | 用户自定义技能 |

### 2.3 任务(Job)
| 实体 | 说明 |
|------|------|
| 任务 | AI 执行的任务,有状态和进度 |

### 2.4 Sprite(精灵)
| 实体 | 说明 |
|------|------|
| Sprite | AI 角色/人格配置 |

## 3. 业务流程

### 3.1 首次启动流程
```
启动应用 → 检测是否首次 → 显示Setup Wizard → 配置语言 → 配置AI提供商 → 选择技能包 → 验证配置 → 进入主界面
```

### 3.2 聊天交互流程
```
用户输入消息 → 发送到AI提供商 → 接收AI响应 → 显示在聊天界面
```

### 3.3 任务执行流程
```
创建任务 → 分配给AI → 执行任务 → 更新状态 → 完成/失败
```
