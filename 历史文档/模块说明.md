# STO-CLAW 模块说明

## 1. 项目架构概述
本项目采用 **Electron + React + TypeScript** 架构,基于 Vite 构建工具,使用 TailwindCSS 样式框架。

## 2. 模块划分
```
sto-claw
├── src/ (渲染进程-前端)
│   ├── pages/ (页面,14个)
│   ├── components/ (组件,7个)
│   ├── stores/ (状态管理,15个)
│   ├── lib/ (工具库,15个)
│   ├── hooks/ (自定义Hooks,4个)
│   ├── i18n/ (国际化)
│   ├── types/ (类型定义,9个)
│   └── styles/ (样式)
├── electron/ (主进程-后端)
│   ├── main/ (主入口,19个文件)
│   ├── api/ (API接口,7个)
│   ├── gateway/ (网关,22个)
│   ├── services/ (服务,9个)
│   ├── utils/ (工具,45个)
│   ├── preload/ (预加载)
│   └── shared/ (共享)
├── shared/ (共享代码)
├── sto-plugin/ (申通插件)
├── scripts/ (构建脚本,15个)
├── tests/ (测试)
└── docs/ (文档)
```

## 3. 技术栈
| 技术 | 版本 | 用途 |
|------|------|------|
| Electron | - | 桌面应用框架 |
| React | - | UI 框架 |
| TypeScript | - | 类型系统 |
| Vite | - | 构建工具 |
| TailwindCSS | - | 样式框架 |
| pnpm | - | 包管理 |
| electron-builder | - | 打包工具 |
| Vitest | - | 测试框架 |

## 4. 核心模块说明

### 4.1 渲染进程(src/)
- pages: 页面组件(登录、欢迎、主界面、设置、任务、Sprite等)
- components: 通用组件
- stores: 状态管理(Zustand/Redux)
- lib: 工具函数库
- i18n: 国际化配置

### 4.2 主进程(electron/)
- main: Electron 主进程入口
- api: API 接口封装
- gateway: 网关服务(22个文件)
- services: 后台服务
- utils: 工具函数(45个文件)
- preload: 预加载脚本

### 4.3 插件系统
- sto-plugin: 申通自定义插件
- sto-dynamic-agent-route: 动态代理路由
