# STO-CLAW 数据存储结构

## 1. 存储概述
- 存储类型: 本地文件系统
- 存储格式: JSON/SQLite
- 存储位置: 用户数据目录

## 2. 核心数据结构

### 2.1 配置数据
| 字段 | 类型 | 说明 |
|------|------|------|
| providers | Array | AI提供商配置列表 |
| language | String | 界面语言 |
| proxy | Object | 代理配置 |
| theme | String | 主题设置 |

### 2.2 任务数据
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 任务ID |
| name | String | 任务名称 |
| status | String | 状态 |
| createdAt | Date | 创建时间 |

### 2.3 Sprite数据
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | Sprite ID |
| name | String | 名称 |
| config | Object | 配置 |
