# CLI 核心事项对焦会议纪要 (0421)
## 会议概况
- 会议主题：CLI 架构与规范对焦
- 会议时间：4月21日
- 涉及模块：业务域 CLI、CLI 网关、Agent
## 决议与核心内容
### 业务域 CLI 规范
- 开发语言：统一使用 Golang 进行开发。
- 部署方式：采用 OSS 挂载形式，挂载至 Agent 下，由公共 sai-cli 负责路由。
- 鉴权机制任意一种：
    - Token 获取：读取统一路径 ~/.sai/sso-auth.json 文件。
    - 参数传入：支持由 CLI 网关通过参数传入，格式为 sso-auth: {xxxxx}。
- 更新发布：业务 CLI 包更新后，需自行上传至约定的 OSS 路径（具体路径详见接口文档）。
###  CLI 网关能力
网关需向下游 CLI 提供以下接口支持：
- 元数据生成：支持通过自然语言描述，生成命令元数据信息及 Tag 信息，业务系统修改确认。
- 发布通知：提供 CLI 命令上报接口，用于发布更新通知并同步更新网关命令清单。
### Agent 职责
- 认证流程：通过 SSO 单点登录接口获取 Token 及用户信息。
- 信息存储：将认证信息保存至本地文件 ~/.sai/sso-auth.json。
- 鉴权标准：全链路涉及权限认证时，统一使用 SSO Token。
