**1. 项目概览**

- 方案对齐： 移动端AI产品首版Demo演示，对焦产品演进方向。
- 一期功能确定： 梳理并锁定一期MVP范围，涵盖输入交互、结构化对话流及框架形式，明确了各模块间的功能边界与逻辑权重。
- 交互规范提炼： 针对汇报反馈，开始沉淀适配HTML原型输出的设计规范，确保AI自动生成的界面在输入输出体验上具备高度一致性。
- 计划明天下午组织一期功能评审，目前进度正常。


**2. 一期核心功能**


| 内容        | 本期范围                                      | 任务拆解                                                                                             |
| --------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **首页框架**  | 顶部导航 + 中间品牌IP透出 + 底部输入区，去掉底部 Tab          | * 首页框架样式 * 视觉风格定义                                                                                |
| **侧边栏导航** | 左滑呼出，包含「新建对话」「历史会话时间轴」「用户信息」              | * 定义侧边栏信息层级 * 明确入口/关闭的交互                                                                         |
| **历史会话**  | 列表展示（分组），支持重命名、删除； 启动时自动恢复上次会话            | * 确认分组规则（今天/昨日/更早） * 定义列表项字段（标题、时间、最后一条消息摘要），明确删除/重命名的交互                                         |
| **新建会话**  | 侧边栏新建对话，点击进入空白页并自动唤起键盘                    | * 状态流转图 * 点击后旧会话如何处理（本地保存还是暂存草稿）                                                                 |
| **输入框**   | 默认态/聚焦态切换；多行自适应                           | * 定义各状态下的精确样式和动效 * 约定最大行数、键盘避让规则等                                                                |
| **对话流**   | 用户气泡、Agent 气泡；支持 Markdown 渲染（标题、列表、表格、链接） | * 确认一期可以接入哪些数据源； * 确认数据API中是否含有数据权限的问题，确认不越权的问题 * 对话气泡样式，文本结构化规范 * Markdown渲染样式规范，标注哪些语法支持、哪些不支持 |
|           | Agent 任务过程展示                              | * agent任务步骤 * 异步任务如何展示，是否折叠等细节（参考IDE的任务进展形式） * 思考过程中多状态的样式细节                                     |
|           | 能力路由与调用                                   | 自动路由、调用感知、路由纠偏                                                                                   |
|           | 消歧与多结果引导、意图确认                             | 命中多个相似指标时展示候选项供用户确认                                                                              |
|           | 数据结果呈现及异常提示                               | * 多域数据场景（如一期有多域数据） * 未产出、维度不支持、数据源不可用时给出原因和替代建议                                                  |
|           | 对话边界（越界处理）                                | 能力越界、知识越界、角色越界、闲聊越界                                                                              |
|           | 能力降级策略                                    | 单能力不可用、全部不可用、超时                                                                                  |
|           | 权限边界提示                                    | 无权限时指向归属方，部分权限时标注实际数据范围                                                                          |
|           | 回答后追问                                     | * 确定设计追问形式，采用可交互点击形式还是多轮文本对话形式的细节思考 * 追问推荐逻辑，确定一期追问内容是否固定或由后端返回                                  |
|           | 反馈                                        | 反馈入口、流程                                                                                          |
| **异常状态**  | 网络断开、服务错误、单号不存在等状态下的展示                    | 梳理异常状态场景，提供文案和图示                                                                                 |


部分功能如一期无法支持，按大模型推理结果，不做限制
