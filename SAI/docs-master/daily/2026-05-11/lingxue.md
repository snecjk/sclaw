####  后续业务人员自助编写清单(简化版)
> 给一线业务人员的精简版,聚焦\"业务该做什么决定\",技术细节由产品 / 开发承接。   

| 序号 | 关注点 | 怎么填 |
|------|---------|---------|
| 1 | 指标命名 | 跟现有报表 / 系统名称保持一致,**不要发明新名字** |
| 2 | 触发词 | 站在用户视角,想 5 个**业务同事会怎么问**(例:不写\"准点率\",而是写\"准点怎么样\"、\"达标率\"、\"准时不准时\") |
| 3 | 数据维度 | 明确指标支持哪些维度(全国 / 大区 / 省区 / 网点 / 中心),错位会让 Agent 调错 |
| 4 | 数据周期 | 写清 **T-1 / T-2 / T-5**(运营对周期敏感) |
| 5 | 出参字段中文名 | 用业务听得懂的中文,Agent 才能\"说人话\" |
| 6 | 组织名称 | **不要写\"上海转运中心\"等具体名称**,用代号 / code |
