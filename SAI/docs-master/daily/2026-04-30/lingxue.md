# 1. 梳理 运营 AI 接入与自动注册 CLI流程

打通ODPS/引擎 → AI运营专家 → SAI-CLI 自动注册的完整链路,产品在指标接入页配置后可一键完成 SAI-CLI 注册，与 tag 修改；未来AI运营专家可无缝接入SAI-CLI；

```
┌──────────────────────────────────────────────────────────────┐
│  第一步:ODPS 数据接入(AI运营专家)                              │
│  ① 指标相关解释:名称、描述、领域、业务域、触发词、相似词等   │
│  ② 表字段接入:字段、中文名、含义解释、字段类型               │
└──────────────────────────────────────────────────────────────┘
                              ↓ 封装成API接口
┌──────────────────────────────────────────────────────────────┐
│  第二步:点击「CLI 注册」,系统自动映射至 9 维 Tag 体系        │
│  D1 指标领域 / D2 指标名称 / D3 业务域 / D4 全量字段          │
│  D5 指标类型 / D6 维度限制 / D7 触发词+相似词                 │
│  D8 查询模式(单点/趋势) / D9 出参字段                        │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│  第三步:请求 tag 获取接口 → 拿到 tag 并保存                   │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│  第四步:tag + 上述信息一并注册到 SAI-CLI                         │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│  第五步:注册成功,产品可在 SAI-CLI 后台查看并修改 tag             │
└──────────────────────────────────────────────────────────────┘
```
