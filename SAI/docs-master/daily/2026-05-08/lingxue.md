### 1. 省总日报 Skill 体系架构设计

为保证 skill 数据获取**准确性**，完成整体分层设计。核心思路：**指标以 code 方式映射在 Skill 层**，后续业务可自助新增/修改指标 code，简化配置逻辑；同时暴露统一入参能力（时间、组织、聚合、过滤）。

Agent → Skill → CLI → 底层数据，所有数据通过映射 code 的形式在 skill 中呈现，以便后续允许业务修改新增对应的指标 code，简化配置逻辑。同时暴露基本的入参能力，可调整时间、组织、聚合、过滤等。

**Skill 层**是入口，核心职责是把抽象的指标请求结构化为两类信息：
- **指标映射 Code**：维护 metric ID 到具体查询代码/模板的映射关系
- **基本入参**：时间范围、组织维度过滤、聚合粒度等通用参数

**CLI 层**用来执行，封装用户的参数构建完成查询指令并调用底层数据接口
