## 一、各模块进展

### 1. 申懂懂 Channel 产品开发与增量数据流

- agent-gateway 新增附件管理功能，包含 OSS 配置、文件上传服务及文件信息管理模块，共涉及 15 个文件变更，新增约 450 行代码
- 对话流式处理逻辑优化，精简 ChatStream 相关处理流程
- agent-gateway 性能优化：WebClient 从每次创建新实例改为使用 Spring Bean 单例连接池，提升连接复用效率
- agent-gateway 稳定性修复：修复客户端断开连接时 AsyncContext 被重复 complete 导致 IllegalStateException 的 bug
- agent-gateway 新增 CLAUDE.md 开发规范文档

### 2. Agent 基础能力建设

#### Serverless 环境

- 自建 FC 504 超时问题持续排查中
- 自建 FC 运维问题（POD 登录及日志查看）运维团队持续推进中
- 出口域名白名单方案运维团队仍在准备中，预计下周给出

#### Agent 内部信息安全

- 信息安全机制方案方向已确定，涵盖四个维度：系统提示词层敏感信息拦截、用户独享 AK 分配、环境变量用户独享隔离、服务二进制编译加密

#### Skills 优化与对接

- 线索管理 Skill 的 HTTP 客户端从 aiohttp 迁移至 httpx，统一超时和错误处理机制
- 线索计数接口新增领取日期参数支持按日查询，移除领取前的重复确认步骤，优化业务流程
- 解决 demo 业务 Skill 之间的冲突问题
- agui Skill 目录从 marketing 业务目录迁移至 src 系统目录，清理旧版本解决目录冲突

#### Agent 工作空间与日志

- Agent 用户文件固定到 workspace 目录，日志输出标准化改造

### 3. 通用Agent前端 H5 SDK

- 跑通前端渲染增强 Skill 方案：前端提供渲染 Skill，模型输出特定格式 code block 后，前端解析并渲染为通用组件
