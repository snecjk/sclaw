# 项目日报

# 1. 管家域 CLI 开发规范

| 问题 | 结论 |
|------|------|
| 开发语言选型 | 统一使用 **Golang** |
| 部署方式 | 采用 **OSS 挂载**形式，挂载至 Agent 下，由公共 `sai-cli` 负责路由 |
| 鉴权 Session 获取 | 读取统一路径 `~/.sai/sso-auth.json` |
| 鉴权参数传入 | CLI 网关通过参数传入，格式为 `sso-auth: {xxxxx}` |
| 更新发布流程 | 业务方自行上传至约定的 OSS 路径（具体路径见接口文档） |

# 2. CLI 网关能力

| 问题 | 结论 |
|------|------|
| 元数据生成 | 网关支持通过自然语言描述生成命令元数据及 Tag 信息，业务系统修改确认 |
| 发布通知 | 提供 CLI 命令上报接口，用于发布更新通知并同步更新网关命令清单 |

# 3. 于Agent 职责

| 问题 | 结论 |
|------|------|
| 认证流程 | 通过 SSO 单点登录接口获取 Token 及用户信息 |
| 信息存储 | 认证信息保存至 `~/.sai/sso-auth.json` |
| 鉴权标准 | 全链路统一使用 SSO Token |
