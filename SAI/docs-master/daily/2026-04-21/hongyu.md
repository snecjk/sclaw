**3. 痛点分析**


| 大类   | 覆盖模块（来自《申懂懂问题分析与设计策略》） | 旧版痛点（汇总关键词）                                               | 设计策略（汇总关键词）                                                                                   |
| ---- | ---------------------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 框架   | 首页、导航                  | 非 Chat-first；冷启动弱；富内容承载弱；入口分散；缺少索引面；长尾能力无承载；Tab 上限/功能堆栈风险 | 单页主场 + 侧滑索引；去底部 Tab；Smart Prompts；Follow-up Prompts；侧边栏承接历史/管理/长尾能力（能力中心/二级页承载）               |
| 会话管理 | 历史会话、新建会话              | 历史入口分散且弱管理；结构不清晰；不强调会话恢复；新建/历史并列堆叠、链路不短                   | Session Resumption；历史时间轴分组 + 重命名/删除；`[+]` 新建会话 + Initial State 重置；侧边栏常驻新建入口                   |
| 对话流  | 输入框、语音输入、快捷指令          | 输入能力单一、扩展性差；长文本编辑弱；键盘遮挡/空间浪费；语音多手势误触高；快捷指令结果不可预期          | 输入框底部固定 + 多行自适应 + `+` 收纳扩展 + 全屏编辑 + 状态机；语音转录范式（非 Live）+ 点击录音 + 流式转录 + 权限三态；常驻快捷标签（可编辑再发送、角色化） |


**4. 对话策略分析**


| #   | 功能名称      | 核心描述                       | 优先级 |
| --- | --------- | -------------------------- | --- |
| 1   | 意图路由与能力调用 | 自动识别意图并调用对应能力，无法判断时让用户选择   | P0  |
| 2   | 来源标注与可信度  | 回答附带来源角标，点击查看数据域、口径、更新时间   | P0  |
| 3   | 数据异常提示    | 未产出、维度不支持、数据源不可用时给出原因和替代建议 | P0  |
| 4   | 权限边界提示    | 无权限时指向归属方，部分权限时标注实际数据范围    | P0  |
| 5   | 对话边界引导    | 超出能力范围时按场景引导回可服务方向         | P0  |
| 6   | 能力降级与兜底   | 能力异常时按置信度切换备选或展示兜底提示       | P0  |
| 7   | 路由纠偏      | 用户可手动触发切换能力重新回答            | P1  |
| 8   | 结构化反馈     | 支持"有用/没用"评价和补充说明，采集用于迭代    | P1  |
| 9   | 消歧与多结果引导  | 命中多个相似指标时展示候选项供用户确认        | P2  |


**优先级说明**：P0 = MVP必须交付；P1 = 应交付，不阻塞核心流程；P2 = 基础预留，完整实现放二期
