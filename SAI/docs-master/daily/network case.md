case1:网点健康度(API: ads_compass_dtcs_net_health_gpt)
API描述
专用于"网点健康度"相关指标：网点健康分、网点星级、健康度指标值及得分（指标包含业务量达成、签收达成率、标签履约率、工单及时解决率、工单虚假完结率、进港投诉率、虚假签收率、遗失率、破损率、交货滞留率、监控罚次数、行政处罚次数）等相关指标查询。支持按自然月、周查询网点数据。

• 参数说明

必传参数
查询组织：可选范围为总部、省区、片区、网点，支持传入单个组织查询
查询时间：必须传入时间周期（自然月或自然周）
可选参数
查询字段：可选择单个或多个指标（如指标包含业务量达成、签收达成率、标签履约率、工单及时解决率、工单虚假完结率等）进行查询
默认参数规则
若用户为总部、省区、片区，且未主动指定查询组织，系统默认按照当前用户所属网格化组织层级，自动返回对应层级下网点星级分布和数量。
若用户为网点，且未主动指定查询组织，系统默认按照当前用户所属网点，自动返回所属网点健康分、网点星级、健康度指标值及得分。
若用户未主动指定查询时间，系统默认按最近1个月有网点健康分得分的进行返回。

• 返回结果要求

低星网点判定规则
如果是查询低星网点，默认取星级为“一星、二星”的网点进行统计。
格式要求
如果返回的内容包含网点健康分、网点星级、健康度指标值及得分，依次展示网点健康分、网点星级、健康度指标值及得分。
如果返回的内容包含网点星级分布和数量，按五星到一星依次展示。

• 自然语言调用示例

辖区内低星网点名单
辖区内网点星级分布情况
这个月健康分掉得挺多，主要是哪些指标扣分了？
咱们片区这个月有几个一星网点？平均分多少？




case2:派件履约指标查询(API: data_cener_net_index_performance_summary_site_new)
• API描述
专用于"派件履约"相关指标：按需派送量、未按需派送量、按需派送率、按需派送率目标、客户声音履约量、客户声音履约失败量、客户声音履约率、客户声音履约率目标、派前打电话履约量、派前打电话履约失败量、派前打电话率、派前打电话率目标、签收后短信量、签收后短信未履约量、签收后短信率、签收后短信率目标等相关指标查询。支持按照日期区间、组织层级进行数据筛选查询。

• 参数说明
必传参数
查询组织：可选范围为总部、省区、片区、网点、承包区，支持传入单个组织查询
查询时间：必须传入开始时间、结束时间，时间统一格式：2026-04-17 14:40
可选参数
查询字段：可选择API下单个字段进行查询
默认参数规则
若用户未主动指定查询组织，系统默认按照当前用户所属网格化组织层级，自动返回对应层级范围内数据。

• 返回结果要求
异常判断规则
指标履约不达标判定：如果字段值出现任意一种，如 按需派送率 ＜ 按需派送率目标、派前打电话率 ＜派前打电话率目标、签收后短信率 ＜ 签收后短信率目标、客户声音履约率 ＜ 客户声音履约率目标，即判定该指标履约不达标。
指标履约数据量异常判定：如果字段值出现任意一种，如未按需派送量＞0、派遣打电话履约失败量＞0，签收后短信未履约量＞0，客户声音履约失败量 即判定该环节存在履约异常工单 / 订单，即判定该指标履约数据量异常。
格式要求
如果是查指标值，根据指标名称相关性，依次展示指标名称、具体数值、目标值。
如果是查指标异常，根据指标名称相关性，依次展示异常指标名称、当前履约率、目标值、差值、未履约 / 失败数量。

• 自然语言调用示例
按需派送量是多少
哪些派件履约指标异常
查询某具体组织的派件履约数据
