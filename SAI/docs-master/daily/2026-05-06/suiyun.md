## 二、桌面版小精灵（一键装机能力）

**定位**：面向用户的 **虾** 或 **Agent** 运行环境，提供类似 **CC Switch** 的「一键切换 / 一键就绪」体验，核心能力是 **一键安装 Skill 与 sai-cli**，降低环境与工具链的配置成本。

**方案要义**：托盘常驻的终端侧统一入口；**Go + Wails** 负责 OS 相关能力（托盘、本地文件与进程、CLI/IDE 检测、下载与更新），**React** 负责界面与交互；业务与编排依赖 **memory-center** API——查询类由前端直连，需落盘或系统调用的操作由 Go 执行并通过事件回推前端；**CLI 与 Skill** 统一安装管线（本地目录写入、CLI 类配合 PATH），并支持向目标 Agent 的 Skill 目录下发。更细的架构与接口以仓库内设计文档为准：[sai-桌面精灵设计方案.md](../../../doc/sai-cli/0506/sai-桌面精灵设计方案.md)。
