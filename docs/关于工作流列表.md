# 关于工作流列表

## API 端点总览

| 端点 | 方法 | 数据类型 | 作用简述 |
|------|------|---------|---------|
| `/agent/v1/workflow-templates` | POST | **模板**（仅系统/官方） | 官方推荐模板列表，分页搜索 |
| `/agent/v1/workflow-templates/mine` | POST | **模板**（系统+个人） | @deprecated 已废弃，前端不再调用 |
| `/agent/v1/workflow-templates/search` | POST | **模板**（仅系统/官方） | 关键词搜索模板 |
| `/agent/v1/workflow-templates/{id}/startup-schema` | GET | **模板** | 获取模板启动参数 schema |
| `/api/my-tasks/agent/v1/my-workflow` | GET | **实例**（用户执行记录） | 用户工作流实例列表（含关联的 templateId） |

**关键区分**: 模板 = 可复用的蓝图；实例 = 每次执行创建的独立记录。

## 首页展示

### Chat `/` Picker（工作流模版列表）
- **端点**: `POST /agent/v1/workflow-templates`（路径前缀 `/agent/v1/`）
- **参数**: `{ query?, page: 1, pageSize: 20 }`
- **数据**: 仅返回 `scope=system` 的官方推荐模板
- **用途**: Picker 预加载模板供用户选择，选择后创建新的工作流实例
- **调用方**: `src/stores/workflows.ts` → `listWorkflowTemplates()`

---

## 我的任务默认推荐展示

- **端点**: `GET /api/my-tasks/agent/v1/my-workflow`（路径前缀 `/api/my-tasks/`）
- **参数**: 无
- **数据**: 返回 `{ id, name, description?, templateId? }` 简单列表（工作流**实例**）
- **用途**: 「我的任务」页面工作流下拉选择器
- **调用方**: `src/pages/MyTask/api.ts` → `fetchWorkflows()`

---

## 官方推荐工作流模版

- **端点**: `POST /agent/v1/workflow-templates`（路径前缀 `/agent/v1/`）
- **参数**: `{ query?, page: 1, pageSize: 100 }`
- **数据**: 仅返回 `scope=system` 的官方推荐模板
- **用途**: 工作流页面「官方推荐」tab 展示
- **调用方**: `src/pages/Workflow/use-workflow-list.ts` → `listWorkflowTemplates()`

## 模板 vs 实例

- **模板 (template)** = 蓝图，一个模板可反复执行
- **实例 (instance)** = 每次执行创建一条独立记录，拥有自己的 `workflowId` 和 `runId`

Picker 每次执行都会创建一条新的工作流实例（不是模板），调用链路如下：

```
createAndStartWorkflowDirect()
  ① POST /agent/v1/workflows          → 创建实例，返回 workflowId
  ② POST /agent/v1/workflows/{id}/start → 启动执行，返回 runId
```

**同一模板执行 N 次，就会在 workflow 表里产生 N 条实例记录。**
