### P1 — 切断 openclaw 双写源头 ✅（2026-07-24 验收通过）

**问题（已核实）**：cutover 已删 HostApi `case 'cron'`，但 openclaw **内置 `cron` 工具在 Gateway 进程内直接 `cron.add`→`jobs.json`**，不经 StoClaw HostApi——故仅删 IPC 不够。

**做法**（deny + 引导新 API）：

1. `tools.deny` 加入 `cron`，放开 `create_scheduled_task`
2. 插件工具经 HostApi 只写 `schedule_tasks`
3. 清掉 gateway client 残留 cron RPC

**验收**：用户本机重启后确认通过（NL 建任务只落 SQLite；`jobs.json` 不回写）。
