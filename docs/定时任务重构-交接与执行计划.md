**问题**：即便迁移清空 `jobs.json`，openclaw NL / 旧 IPC `cron.add` 仍可能再写入 Gateway cron。

**目标**：

- HostApi / IPC `case 'cron' create|update|…` 改委托 `ScheduledTaskService`（或明确 deny + 引导新 API）
- 确认无 `cron.add` 生产写入残留（grep 闸门）
- MyTask / NL 两引擎创建只落 `schedule_tasks`

**验收**：新建 openclaw 任务不写 `jobs.json`；只出现 SQLite 行 + generic scheduler `next_run_at`。
