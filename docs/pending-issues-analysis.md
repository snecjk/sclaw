## 二、P0 — 阻断使用（建议优先）

### P0-1 网关长时间「连接中」无法发消息

| 项 | 内容 |
|----|------|
| **来源** | 运营 #10；孙悦（Windows 环境） |
| **现象** | 端口 18789 握手卡住，输入框灰显「网关未连接…」，无法发送消息 |
| **根因分析** | Gateway 启动有 `waitForGatewayReady`（~60s 超时）+ `scheduleReconnect`；渲染层 WS 另有独立超时（`api-client.ts`）。Windows 上进程启动慢、端口占用或旧进程残留时，UI 长时间无明确失败提示与重试入口 |
| **建议方案** | ① 连接超 30s 显示「启动失败 + 重试/查看日志」② Main 暴露 `gateway:restart` ③ 失败自动重试 2–3 次 ④ Windows 首启增加健康检查日志 |
| **改动文件** | `electron/gateway/*`、`src/stores/gateway.ts` |
| **预估** | 2–3 天 |
| **负责人** | 李峥 |

### P0-2 文件预览路径错误

| 项 | 内容 |
|----|------|
| **来源** | 运营 #11、#12；陈晶晶「文档预览未成功」 |
| **现象** | ① `[file-preview: …]` 点击无响应 ② ENOENT：`/.stoclaw/...`（缺 home 前缀）③ `.tsv` 被截断为 `.ts` |
| **根因分析** | `ChatMessage.tsx` 已将 tag 转为 `preview://`；`files.ts` 的 `resolveWorkspaceFilePath` 支持 `~` 但不处理 `/.stoclaw`；`PREVIEWABLE_FILE_EXTS` 同时含 `ts`/`tsv`，正则可能短匹配优先 |
| **建议方案** | ① `/.stoclaw`、`./.claw-output` 补全为 `~/.stoclaw/...` ② 扩展名最长后缀优先（`tsv` > `ts`）③ 预览前 fuzzy 匹配（`.ts` 不存在试 `.tsv`）④ 统一 `preview://` 点击处理 |
| **改动文件** | `src/pages/Chat/message-utils.ts`、`electron/api/routes/files.ts`、`src/pages/Chat/ChatMessage.tsx` |
| **预估** | 1–2 天 |
| **负责人** | 曹宇 |

### P0-3 工作流执行完成后自动又发消息、重复执行

| 项 | 内容 |
|----|------|
| **来源** | 陈晶晶 #52 |
| **现象** | 工作流执行完成后，自动再发一条消息并再次执行 |
| **根因分析** | `applyWorkflowRunStarted` 追加本地 turn + 启动 tracker；`message-queue.ts` 的 `createAutoSendWatcher` 在 workflow 路径可能再次 `sendMessage`；完成态未清理 pending/队列或 completion 触发二次 send |
| **建议方案** | ① 启动后立即 `clearPendingWorkflow()` + runId 防重入 ② workflow 路径不走 Gateway `sendMessage` ③ completion 只更新卡片 ④ idempotencyKey 去重 |
| **改动文件** | `src/lib/workflow-run-started.ts`、`src/hooks/use-workflow-send.ts`、`src/stores/message-queue.ts`、`src/stores/chat/runtime-send-actions.ts` |
| **预估** | 2–3 天 |
| **负责人** | 曹宇 |

### P0-4 工作流取消后仍在执行

| 项 | 内容 |
|----|------|
| **来源** | 星柠 #70 |
| **现象** | 用户取消工作流后，后端仍在跑 |
| **根因分析** | `workflow:stopTracking` 仅停前端轮询；`isWorkflowCancelIntent` 只 `clearPendingWorkflow()`，未调后端 cancel |
| **建议方案** | ① 调后端 cancel API ② UI：stopTracking + cancel + 卡片标 `cancelled` ③ 忽略已取消 runId 的 poll 事件 |
| **改动文件** | `electron/main/services/workflow-execution-tracker.ts`、`src/hooks/use-workflow-send.ts`、workflow API |
| **预估** | 1–2 天（依赖后端 cancel 接口） |
| **负责人** | 文鹏 |
