## 1. 绝对铁律

1. **范围 = 本任务列出的改动**（见 §2/§4）；任务一~四、侧边栏的组件本轮不碰。
2. **不改功能/逻辑**：`refresh()`、`toggleThinking`/`showThinking`、搜索（`ChatSearchBar` 的 `isOpen/onToggle/...`）、打开预览（`setShowPreviewPanel(true)` / `openArtifactPreview`）——**沿用现有 handler，只搬位置 + 换样式**。
3. **样式按图一/设计稿改**；**精确值（高度/内距/字号/图标尺寸/颜色/分隔线）以 MasterGo MCP 为准**（见 §3），找不到对应 token 不要造，列出来问。52px 复用 `--sto-header-h`（已=52px）。
4. **写法遵守 02-styles**：Tailwind + `cn()`；禁止 inline 视觉值、模板字符串拼 className、无注释裸 hex；现有 `dark:` 与 `var(--sto-...)` token 保留。
5. **横切统一 token + 品牌色**：品牌色 `#FF6700` / `text-primary`，不引入 `#FF6F00`。
6. 要去掉的引擎/模型选择器改为**条件隐藏 + 注释**，不真删组件/import（见 §4.4）。
7. **两阶段**：先按 §6 阶段一交「方案 + 现状分析」，**等用户确认后**再写码。遇到 🟥 停下来问。

## 4. 改动明细

### 4.1 新增 52px 全宽标题栏（结构）

- 在对话内容区**顶部**新增一条 **`shrink-0`、高 52px、贯穿内容区全宽**的标题栏（不再像现在那样塞进居中 862 列）。
- 背景/圆角与卡片容器 `stoMainCardShellClass` 一致（同 `--sto-main-card-bg`，顶部圆角对齐），底部一条分隔线（值取 MasterGo）。
- 标题栏**之下**才是原有的居中列（消息列表 + 输入框）；原 `index.tsx` L459–481 的头部行**移除/替换**为这条标题栏。
- 布局：`flex items-center justify-between`，左 = 标题，右 = icon 组。

### 4.2 左上角：会话标题

- 显示**当前会话名称**，数据来自 `currentSession`（`index.tsx` L94–96）的 `label`/`displayName`。
- 命名回退建议**复用侧栏同源逻辑**（`sessionLabels[key]` → `label` → `displayName` → 默认「新对话」），避免标题与侧栏不一致。🟥 见待确认（取值口径）。
- 超长 `truncate`，给右侧 icon 组留出空间。

### 4.3 右侧 icon 组（从右到左：预览 / 思考 / 刷新 / 搜索）

即从左到右排列为 **搜索 → 刷新 → 深度思考 → 预览**，全部复用现有逻辑：

| icon（右起） | 复用 | 说明 |
| --- | --- | --- |
| 预览 | `setShowPreviewPanel(true)`（现浮动钮 L694–706 的逻辑） | 有产物/工作流时可点（`canShowPreviewPanel`）；并入标题栏后**移除右上角浮动「预览」钮**（条件隐藏 + 注释） |
| 深度思考（收起/展开） | `toggleThinking` / `showThinking`（Brain） | 开启态高亮（沿用 `bg-primary/12 text-primary`） |
| 刷新 | `refresh()`（loading 时转圈 + 禁用） | 同现状 |
| 搜索 | `ChatSearchBar`（`isOpen/onToggle`） | 作为 icon；展开搜索框的呈现方式按设计稿（保留现有展开逻辑） |

- icon 样式统一按 MasterGo（图一是圆形浅底图标钮）。

### 4.4 去掉头部的引擎 / 模型选择器 🟥

- 头部**不再渲染** `ChatEngineSelector` / `ChatModelSelector`（条件隐藏 + 注释，不删组件/import）。
- ⚠️ **风险**：默认对话页的 `ChatInput`（非 home 变体）footer **当前没有**这两个选择器（`toolbarInlineSelectors` 仅在 `composerLayout==='home'` 分支渲染，`ChatInput.tsx` L907）。图二底部虽显示 `OpenClaw / 模型`，但需确认那是哪条分支。**直接删头部会导致无法切换引擎/模型**。
- 🟥 **必须先确认**：引擎/模型移到**底部输入框**（启用默认 ChatInput 的内联选择器 / 复用 home 那套），还是另置？确认后再动，别删没了功能。

### 4.5 标题栏与窗口控件的左留白 🟥

- 省区(provincial)壳层无整行顶栏，内容区顶到窗口顶（参考任务四 §4.3）。**侧栏收起**时，交通灯/折叠钮在左上角，标题栏左端文字可能被压。
- 做法：标题栏左侧在**侧栏收起态**预留 `--sto-chrome-h` 宽度的留白（展开态侧栏占位则无需）；与任务四的预览遮挡同源处理，**不动全局 chrome 浮层**。
