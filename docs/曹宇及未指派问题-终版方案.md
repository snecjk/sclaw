### STO-63 — 工作流执行时间

| 项 | 内容 |
|----|------|
| 根因 | API `startedAt ≈ completedAt`；卡片仅在 `isRunning` 时显示耗时 |
| 改动 | `format-workflow-duration.ts`（已有）、`workflow-card-state-merge.ts`（已有）、`WorkflowCard.tsx` 完成后也展示 `durationLabel` |
| 验收 | 运行异常监控等工作流至完成，卡片应显示合理耗时（非 0–1 秒） |

### STO-61 — 后台字段对用户不可见

| 项 | 内容 |
|----|------|
| 根因 | 参数确认/完成摘要直接展示 `SERIOUS_DROP` 等 schema/表字段名 |
| 改动 | 新增 `src/lib/workflow-user-facing-text.ts`；`WorkflowCard` 摘要 `sanitizeWorkflowSummaryText`；`workflow-form-utils.formatWorkflowObjectLines` 无 items 时用中文 label 并过滤内部 key |
| 验收 | 完成卡片摘要与参数确认区不出现裸 `VOLUME_ABNORMAL` / `belong_org_id` 等；已知阈值项显示中文名 |
