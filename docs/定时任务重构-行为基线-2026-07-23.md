## D. 关键行为事实（供 Step 5/7）

1. **dated 会话双引擎都有**：openclaw `agent:main:cron:{jobId}:{date}` + claude `claude-task:{taskId}:{date}`。dated 会话 `engine_session_id=NULL`（无引擎绑定）；run 会话有绑定 + cwd。Step 5 session_type 迁移须区分 `:run:` 与 `:date` 两类 session_key 变体，不能只看 session_type。
2. **openclaw 手动跑**：追加 `runs/{jobId}.jsonl`（不建新文件）+ 建 1 个 dated cron 会话（不建 run 会话？本次 only dated +1）。
3. **claude 手动跑新任务**：建新 `runs/{taskId}.jsonl`（running→succeeded 2 行）+ 建 2 个 claude_task 会话（run+dated）+ scheduler-state 追踪 + UTC nextRunAt。
4. **run 记录字段 live 实证**：openclaw = `{ts,jobId,action,status,summary,delivered,deliveryStatus,sessionId,sessionKey,runAtMs,durationMs,nextRunAtMs,model,provider,usage}`；claude = `{runId,taskId,status,triggerSource,scheduledFor,startedAt,attempt,idempotencyKey,sessionKey,runtimeSnapshot}`。两引擎 run 历史结构不同，Step 7 须分别对照。
5. **scheduler 时区**：本地 cronExpr → UTC nextRunAt。
6. **交付状态**：openclaw `delivered=False/deliveryStatus=not-delivered`（本次未投递）；claude 无 delivered 字段（投递在 runtimeSnapshot/外部）。
