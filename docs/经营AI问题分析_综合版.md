## 三、逐条问题原因分析与解决方案（综合版）

### 启用旧版本创建的定时任务失败，导致模型不可用，卸载重装也无法使用

- **优先级**：P0
- **负责人**：待定
- **预估工作量**：2-3天
- **涉及代码/模块**：定时任务迁移脚本、Doctor、卸载脚本

**原因分析**：

旧版本定时任务数据格式/存储路径与新版本不兼容，升级后未做数据迁移；卸载时未清理定时任务状态，导致残留配置干扰新安装。

**解决方案**：

1. 旧 cron → 新 schema 迁移，启动时检测旧格式并自动转换；2. 卸载流程清理本地定时任务缓存；3. 无效 model 回退默认；4. Doctor 增加定时任务健康检查；5. 失败时一键修复与中文提示。

---

### 模型切换和模型计费不匹配问题

- **优先级**：P1
- **负责人**：文鹏
- **预估工作量**：2天
- **涉及代码/模块**：模型配置、计费统计、会话状态

**原因分析**：

模型切换后，前端展示模型与后端实际调用模型不一致；计费统计未跟随实际调用模型更新，或计费规则表与模型列表未同步。

**解决方案**：

1. 统一模型选择状态管理，切换模型后立即同步到后端会话配置；2. 计费模块读取实际调用的模型 ID 统计；3. 建立模型-计费规则映射表并做一致性校验；4. 增加模型切换后的计费日志。

---

### cli里的指标名称和sto-claw查出来的不对应 例如：用客户基础资料cli查一下得玩所DEVASO电玩配件 对应的电子面单编码

- **优先级**：P1
- **负责人**：待定
- **预估工作量**：1-2天
- **涉及代码/模块**：shared 指标映射、CLI 输出、GUI 展示

**原因分析**：

CLI 与 STO-Claw 前端使用了不同的指标/字段命名映射层，或 CLI 直接返回原始数据库字段名，前端做了二次转译。

**解决方案**：

1. 提取统一的指标名称映射层（shared 包），CLI 和 GUI 共用；2. 对关键业务指标建立标准命名规范；3. CLI 输出和 GUI 展示都经过映射层处理。

---

### 第一轮对话输出未结束，切换模型，会导致绘画一直不中断

- **优先级**：P1
- **负责人**：待定
- **预估工作量**：1-2天
- **涉及代码/模块**：src/lib/api-client.ts、消息流状态机

**原因分析**：

切换模型时未正确中断当前进行中的生成请求/流式响应，前一次请求的回调仍在继续消费数据并渲染。

**解决方案**：

1. 切换模型前强制 abort 当前请求（AbortController）；2. 在请求状态机中增加「已取消」状态；3. 切换模型后重置当前消息流与加载态；4. 增加边界测试。

---

### 嵌套参数的配置不支持，调用示例生成不标准

- **优先级**：P1
- **负责人**：简鹏
- **预估工作量**：2-3天
- **涉及代码/模块**：参数表单组件、schema 解析

**原因分析**：

工作流/技能参数配置表单只支持一维平铺参数，缺少对嵌套对象/数组结构的 schema 渲染与校验。

**解决方案**：

1. 升级参数表单组件，支持 JSON Schema object/array 递归渲染；2. 根据 schema 自动生成标准调用示例；3. 增加嵌套参数默认值与必填校验；4. 对历史配置做兼容处理。

---

### 周报列表数据支持excel导出

- **优先级**：P2
- **负责人**：曹宇
- **预估工作量**：1-2天
- **涉及代码/模块**：周报列表页、后端导出接口

**原因分析**：

周报列表页面只实现了展示，未实现导出功能；后端可能未提供对应导出接口。

**解决方案**：

1. 后端新增周报导出 API（支持 xlsx）；2. 前端列表页增加「导出 Excel」按钮；3. 导出内容包含当前筛选条件下全部数据；4. 处理大数据量导出加载与失败提示。

- **预估工作量**：2天
- **涉及代码/模块**：入参配置面板、技能/CLI store
