## 1. 绝对铁律

1. **范围 = §3 列出的组件**，其它不动；选项卡卡内样式（任务二）、输入框本体——本轮不碰。
2. **不改功能/接口/逻辑**：接口调用、props 既有签名、hooks、store、事件 handler、流式/收发逻辑、工作流拉取/创建/执行逻辑——一律不动。新增**可选 prop** 不算违规。
3. **思考过程只改样式、不新增逻辑状态**：下列状态都是**现有**的（连接/处理/运行/思考/完成折叠/完成展开/等待），只调视觉 + 文案口径，不改触发时机与展开折叠逻辑。
4. **文案口径按 §2 统一**：设计稿有一批代码没有的新词；改文案 = i18n 文本调整（zh/en/ja 三语同步），**不是逻辑变更**。
5. **样式按设计稿改**；**精确值以 MasterGo MCP 为准**（见 §4），找不到对应 token 不要造，列出来问。
6. **写法遵守 02-styles**：Tailwind + `cn()`；禁止 inline style、模板字符串拼 className、无注释裸 hex、其它样式方案；现有 `dark:` 原样保留。
7. **横切统一 token + 品牌色**：新写/改到的样式用语义 token，品牌色 `#FF6700`/`text-primary`，不再引入 `#FF6F00`（未触及处不强改）。
8. **要删的元素改为条件隐藏 + 注释**，不真删 JSX/常量/i18n。
9. **🟥 新功能必须先确认**：本文档标 🟥 的项（如完成态"赞/踩/重新生成"）超出"纯样式"，实现前停下来问用户。

| 元素 / 状态 | 代码现状（i18n key / 位置） | 设计稿叫法 | 统一口径（实现用词） |

## 5. 逐状态详细规格

> 每个状态：**设计场景** → **代码对应**（现状构件）→ **文案口径** → **样式要点**（我从截图能读到的方向，最终按 MCP）→ **取值**。
> 所有"样式要点"均为**视觉**层；触发时机/数据来源不动。

### A. 普通对话 · 思考过程（4 态）

**A1 正在思考（初始）**
- 设计：一行 `脉冲点 ••• + "正在理解你的问题…"`，灰字。
- 代码：`ThinkingProcessPanel` 的 `isConnecting` 分支 → `ConnectingModelIndicator`（现文案 `connectingModel`="连接模型中..."，**纯文字无脉冲点**）；脉冲点组件是 `ChatMessage` 的 `StreamingPulse`。
- 文案口径：普通对话改用**新增** `understandingQuestion`="正在理解你的问题…"。
- 样式要点：左侧 `StreamingPulse`（`h-1.5 w-1.5 rounded-full bg-primary` 脉冲）+ 灰字 `text-muted-foreground`；整行间距按 MCP。把脉冲点接到该指示器前面。
- 取值：脉冲点尺寸/动画、文字色/字号 → MCP。

**A2 思考中（流式展开）**
- 设计：折叠摘要行"思考 N 次，使用 N 个工具 >" 与正文交替；当前轮思考实时展开，条目有 `深度思考`/`调用工具 – {工具名}`，**单条内容超 4 行内部滚动**。
- 代码：`ThinkingProcessPanel` 展开态（`expanded`，流式时 `useEffect` 自动展开）；思考块 = markdown；工具行 = `ToolCallRow`（现"工具调用 {index}"）；折叠摘要 = `buildCollapsedSummary`。
- 文案口径：折叠摘要→"思考 N 次，使用 N 个工具"；思考块加"深度思考"标签；工具行→"调用工具 – {工具名}"（见 §2）。
- 样式要点：条目 icon（深度思考=对话气泡 icon、工具=工具 icon，按设计 Lucide）；**展开内容容器固定最大高度（约 4 行）+ `overflow-y-auto`**；左侧竖线/缩进按设计。
- 取值：行高、最大高度（4 行）、icon、缩进、颜色 → MCP。

**A3 思考完成（折叠）**
- 设计：每段只剩灰色折叠摘要行"思考 N 次，使用 N 个工具 >"，正文在下。
- 代码：回合结束 `useEffect` 自动折叠；折叠摘要行在 `ChatMessage`（带 `ChevronRight`）。
- 样式要点：灰字 + 右向箭头，hover 变深；行高/间距按 MCP。
- 取值：颜色/箭头/间距 → MCP。

**A4 思考完成（展开）**
- 设计：点开折叠行后，显示"深度思考 / 获取当前时间 / 调用工具 – 竞品分析"各条，每条可再展开内容（4 行+滚动）；底部 `以上信息由 AI 提供 · ✓ 已完成`。
- 代码：同 A2 的展开渲染；完成页脚 = `completedLabel` + `completedBadge`（`ChatMessage` 完成页脚区）。
- 样式要点：完成页脚左 `以上信息由 AI 提供`（`text-[10px] text-muted-foreground`）/ 右 `✓ 已完成`（success 绿，现 `text-emerald-500/70`→统一 `text-success`）；条目同 A2。
- 取值：页脚字号/颜色、条目样式 → MCP。

### B. 创建工作流 - 云端思考（5 态）

**B1 选择模型（初始）**
- 设计：`脉冲点 ••• + "连接模型中…"`。
- 代码：`isConnecting` → `connectingModel`（沿用）+ `StreamingPulse`。
- 样式要点：同 A1，仅文案为"连接模型中…"。

**B2 思考节点**
- 设计："深度思考 >" + "调用工具 – WebSearch: 网络搜索 ⌄"（展开内容如"架构已准备就绪…"）。
- 代码：`ThinkingProcessPanel` 展开/折叠 + `ToolCallRow`；工具名 `WebSearch: 网络搜索` 走 `resolveSkillDisplayName`。
- 文案口径：工具行"调用工具 – {工具名}"。
- 样式要点：同 A2。

**B3 等待选择**
- 设计：业务概述白卡（"工作流「客户异常监控」已就绪，请在下方表单中逐步确认…"）+ `脉冲点 ••• + "Claw将在你回复后继续工作…"`；其下出现**选项卡**（卡本体=任务二）。
- 代码：业务概述 = 助手回合一段卡片（带完成页脚）；等待指示器 = **新增** `awaitingReply`（脉冲点 + 文字）；选项卡 = `ParameterFormCard`（任务二）。
- 文案口径：新增 `awaitingReply`="Claw将在你回复后继续工作…"（或"等待你的回复…"，二者择一，按设计统一）。
- 样式要点：① 业务概述白卡：圆角/描边/内距/底色 + 完成页脚，按 MCP；② 等待指示器：脉冲点 + 灰字，**持续到用户提交**；③ 选项卡本体不在本任务（任务二）。
- 取值：白卡样式、等待行样式 → MCP。

**B4 回填并确认（提交后）**
- 设计：参数回填只读卡（"数据来源（系统预置）… 配置异常判断规则–单量异常 …"）→ "参数已确认 ⌄" 折叠行 → 工作流卡"工作流_000… 已运行 52 秒 · 执行中(绿，转圈)"。
- 代码："参数已确认" 文案在 `lib/workflow-local-turn.ts`（已存在）；折叠行同思考折叠样式；工作流卡 = `WorkflowCard`（`running` 主题，`durationLabel`=`runningFor`）。
- 文案口径：沿用"参数已确认"。
- 样式要点：① "参数已确认" 折叠行 = 思考折叠行同款（灰字 + 箭头 + ✓icon）；② 回填只读卡：标题加粗 + 灰描述，按 MCP；③ 工作流卡 running 态：绿点/转圈 icon + "执行中" + "已运行 52 秒"，统一 `text-success` token。
- 取值：只读卡、工作流卡 running 样式 → MCP。

**B5 产物输出**
- 设计："参数已确认 >" + 完成正文（"…客户异常监控已完成，共监控 90 个客户…"）+ 产物卡（"每周总部对帐单 文档 .html 2026-06-01" + 橙色"查看产物"）+ 底部反馈行（赞/踩/重新生成/复制）。
- 代码：产物卡 = `WorkflowCard` 的 artifact 区（completed 态）或消息内产物卡；"查看产物" 现为橙色文字/描边；反馈行 = `AssistantHoverBar`（**现仅复制**）。
- 样式要点：① 产物卡：图标 + 名称 + 类型/日期 + 橙色"查看产物"按钮（实心/描边按 MCP）；② 反馈行见 §6 🟥。
- 取值：产物卡、查看产物按钮 → MCP。
