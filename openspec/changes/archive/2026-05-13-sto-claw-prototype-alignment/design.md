## Context

参考文件：`其他文件/设计稿/归档/STO Claw/index.html` 与 `styles.css`（BEM + CSS 变量）。当前实现：`MainLayout` 含 `TitleBar` + `Sidebar`（窄轨 `w-[5.25rem]` + 可选 `12rem` 会话列）+ `main` 滚动区；全局为 shadcn/Tailwind 青色系与 `glass` 面板。

## Goals / Non-Goals

**Goals**

- 视觉与排版对齐设计稿中的可复现量：页背景 `#f7f8fa`、侧栏背景 `#f3f4f6`、侧栏宽 `248px` / 折叠 `72px`、主区内层 `max-width: 1100px`、圆角与阴影层级（如 `--radius-card: 24px`、`--shadow-panel`）、主色强调 `#ff8c00` 及其 hover 语义。
- 侧栏信息架构：品牌行 + 折叠按钮、主导航列表、分组标题「任务列表」、可折叠任务组、底部用户卡与弹出菜单结构在 React 中复刻（文案与图标可用 lucide 等价替换，布局优先）。
- 主区首页模块：Hero（Logo + 标题 + 导语）、概览卡横向栅格（含卡片 header / stats / footer 三带）、底部助手输入区（textarea + 工具条 + 发送按钮状态）的结构与间距对齐原型。

**Non-Goals**

- 不在本变更中承诺设计稿内全部业务数据（对账金额、小组头像等）已对接真实后端；允许占位数据或现有 store 的映射，但 UI 结构须可替换数据源。
- 不重写 OpenClaw 消息协议、不新增 renderer 直连 Gateway HTTP。
- 不强制一次 PR 内完成设计稿附属页（如 `task-center.html`、`recon-detail.html`）全站迁移；可作为后续变更。

## Decisions

### 1. 主题实现路径：扩展 CSS 变量 + Tailwind 映射，而非引入第二套全局 BEM CSS

- **决策**：在 `globals.css` 的 `:root` / `.dark` 中增加与原型对齐的语义变量（如 `--sto-page-bg`、`--sto-sidebar-bg`、`--sto-accent`），并在布局组件中用 Tailwind `arbitrary` 或 `@theme` 映射；组件级样式以 Tailwind + 少量局部 class 为主。
- **理由**：项目已统一 Tailwind/shadcn，维护单一路径；整页复制 `styles.css` 会与现有 token、暗色模式、Electron 标题栏区域冲突。
- **备选**：直接 `@import` 原型 `styles.css`。已否决：类名与 DOM 结构强耦合、暗色与玻璃态难以渐进融合。

### 2. 侧栏形态：从「双列（轨 + 会话）」迁往「单列宽侧栏」

- **决策**：以原型为准，侧栏为单列可折叠宽栏；原「会话历史」折叠面板改为侧栏内分组（类似「任务列表」下的可折叠组）或二级列表项，具体交互在实现前与产品确认一则默认方案（推荐：会话归入「对话」分组，保留新建会话与按时间分桶）。
- **理由**：设计稿无独立第二列，硬留双列无法达成排版对齐。
- **备选**：保留双列仅在 Chat 路由显示。已否决：与非 Chat 页侧栏宽度不一致，跨页跳变大。

### 3. 默认路由：首页与对话分离（推荐）

- **决策**：新增「首页」路由（例如 `/home` 或 `/`），将 OpenClaw 对话页迁至 `/chat`（或 `/c`），侧栏主导航「对话」指向新路径；设计稿「首页」对应新页面，「定时任务」等继续指向现有 `Cron` 等路由。
- **理由**：设计稿 `index.html` 主区不是消息列表；强行把 Dashboard 塞进 `Chat.tsx` 会导致职责混乱与性能问题。
- **备选**：保留 `/` 为 Chat，在 Chat 顶部叠放 Dashboard。已否决：与主内容滚动、会话列表焦点模型冲突，且偏离设计稿主结构。

### 4. TitleBar 与原型关系

- **决策**：保留 Electron `TitleBar`；其高度计入纵向节奏，主内容区从 TitleBar 下方开始应用 `bg-page` 与内边距，避免设计稿 web 全高与桌面拖拽区重叠。
- **理由**：平台约束；仅 web 原型无标题栏。
- **备选**：透明标题栏叠在侧栏上。已否决：Windows 控件区与侧栏品牌区对齐成本高、易回归。

## Risks / Trade-offs

| [Risk] | Mitigation |
|--------|------------|
| 会话列表迁入宽侧栏后信息密度变化导致难用 | 保留分桶折叠、搜索（若已有）与右键菜单；首版可用滚动 + 最大高度约束 |
| 主题从青橙切到灰底橙强调后，现有页面（Settings、Models）短暂不协调 | 分阶段替换：先壳层与首页，再按页面迭代 token |
| 路由调整破坏书签与深度链接 | 在 `App.tsx` 增加从旧 `/` 到新 `/chat` 的重定向（若执行拆分） |
| 暗色模式与设计稿（浅色为主）不一致 | 暗色沿用「结构对齐 + 合理降对比」策略，不要求像素级与浅色稿一致 |
