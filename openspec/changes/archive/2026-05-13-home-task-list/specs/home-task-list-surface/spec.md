## 新增需求

### Requirement: 任务列表稳定路由与任务键枚举

系统必须为每条归档原型任务提供稳定的路由片段 `/tasks/:taskId`，其中 `taskId` 必须为以下字面量之一：`hq-reconciliation`、`abnormal-customers`、`outbound-cost`；未知 `taskId` 不得渲染详情正文，且必须将用户带回安全页面（例如应用首页）。

#### Scenario: 合法任务键打开详情

- **WHEN** 用户导航至 `/tasks/hq-reconciliation`（或其它已定义任务键）
- **THEN** 应用必须渲染该任务对应的「最新一条」详情表面，且页面主标题与至少一段摘要文案不得为空白

#### Scenario: 非法任务键被拒绝

- **WHEN** 用户导航至 `/tasks/unknown-id`
- **THEN** 应用不得展示伪造的报表数据正文
- **AND** 用户必须被重定向或引导回已定义的主应用首页路由

### Requirement: 首页概览卡与任务键一一对应并可进入最新视图

系统必须将首页三张数据概览卡分别绑定到 `hq-reconciliation`、`abnormal-customers`、`outbound-cost`；用户点击任意一张卡片时必须导航至 `/tasks/<对应键>`，与侧栏任务列表同一 URL 语义（最新一条）。

#### Scenario: 从首页卡片进入

- **WHEN** 用户点击「昨日总部对账结果」卡片
- **THEN** 浏览器地址栏路径必须为 `/tasks/hq-reconciliation`
- **AND** 详情页展示的内容必须与该任务键配置的文案一致

#### Scenario: 三张卡片互不串台

- **WHEN** 用户依次点击三张不同的首页概览卡
- **THEN** 每次导航后的 `taskId` 必须与卡片所代表的任务类型一致

### Requirement: 侧栏「任务列表」分组与导航

系统必须在侧栏主导航与工作台分组之间展示分组标题「任务列表」（通过 i18n 键），并列出与上述三枚 `taskId` 对应的可点击条目；其中「总部对账结果」条目必须在展开态展示可识别的未读/提醒红点占位（纯 UI，不要求真实未读数接口）。

#### Scenario: 展开态展示分组与链接

- **WHEN** 侧栏处于展开态且用户可见主导航
- **THEN** 用户必须在主导航下方看到「任务列表」标题及三条任务文案链接
- **AND** 点击「总部对账结果」必须导航至 `/tasks/hq-reconciliation`

#### Scenario: 当前任务在侧栏有可见选中态

- **WHEN** 用户位于某一 `/tasks/:taskId` 页面且侧栏展开
- **THEN** 对应任务条目必须使用浅灰表面背景与深色正文的选中样式（对齐 `docs/sto-design.md` 中性背景层级，不得使用 Brand-6 作为该行主背景）
- **AND** 其它任务条目必须保持非选中样式

### Requirement: 任务详情页信息结构

任务详情表面必须包含：返回首页的控件、由 i18n 提供的主标题（含日期与任务副标题组合语义）、至少一段引导摘要、至少一张「汇总」指标表与一张「异常明细」类表（列名与行数据可由占位内容填充），以及页面底部与首页一致的助手 composer 区域（行为须符合既有「复用对话发送链路」约束，不得新增 renderer 直连 Gateway HTTP）。

#### Scenario: 详情首屏结构完整

- **WHEN** 用户打开任一合法任务详情路由
- **THEN** 页面必须展示返回控件、主标题、摘要与两张表的区域
- **AND** 页面底部必须展示与首页相同结构的助手输入与工具行入口

#### Scenario: 发送行为不绕过 host-api 策略

- **WHEN** 用户在任务详情页通过助手 composer 尝试发送消息
- **THEN** 发送路径必须与既有 Chat 存储及 host-api 约束一致
- **AND** 渲染进程不得在该页新增 `fetch('http://127.0.0.1:18789/...')` 调用

### Requirement: 国际化与可维护性

所有用户可见的任务名称、详情标题、表头与占位正文必须可通过 `tasks` 或 `common` 命名空间下的 i18n 键在中英文间切换（项目已支持的语种）；不得在组件内硬编码中文长句作为唯一文案源。

#### Scenario: 语言切换后任务名更新

- **WHEN** 用户在设置中切换显示语言后重新打开任务详情
- **THEN** 任务主标题与表头标签必须随语言资源切换而更新
