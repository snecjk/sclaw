## Why

首页任务卡片与侧栏「任务列表」主项应对齐为同一业务入口：用户点击某张卡片时，应落在**对应主任务**下、以**当日**为语义的材料子项，并进入「以会话为主」的工作面。**首次**为当日创建该子项时，应自动代发该卡片绑定的用户 prompt，减少手动复制；**当日子项已存在**时，再次从首页进入应直接落在既有会话末尾，避免重复代发打断阅读流。静态预置子项列表难以表达「按日生成材料」与「每张卡片各有默认问法」的产品意图；本变更在 OpenSpec 中固化**动态子项**、**卡片级 prompt（仅新建路径使用）**、**同日复用（仅跳转 + 滚底）**、**网关就绪后再发送（仅新建路径）**等行为边界，便于后续接真实数据与多卡片扩展。子项内容页为聊天形态时，用户若尚未进入该子项查看助手已输出内容，应在侧栏对应子项行尾提供**未读提示**（见下）。任务子项上的收发与历史须**仅**在该子项对应的聊天内容区内呈现与延续，**不得**因同一次发送在应用主路径的**普通会话列表**中**再新增一条并列会话记录**。

## What Changes

- **动态子项**：用户点击首页某任务卡片时，系统按「点击瞬间本地日历日」计算 `entryId`（`YYYY-MM-DD`）。若该 `(taskId, entryId)` **尚无**子项，则 **MUST** 创建并注册一条展示语义为「**xxxx年XX月XX日的材料**」的子项；若**已有**，则 **MUST** 复用同一子项（不重复建两条同日条目）。
- **分支 A（新建当日子项）**：创建并注册完成后，浏览器 **MUST** 导航至 `/tasks/<taskId>/<entryId>`，并触发**一轮**由该卡片绑定文案（i18n 集中配置）作为用户消息的**自动发送**；网关未就绪时 **MUST NOT** 发送，须在网关就绪后补发（与既有首页助手前提一致）；须仍走既有 chat / host-api 约束。
- **分支 B（已存在当日子项）**：浏览器 **MUST** 导航至同一 `/tasks/<taskId>/<entryId>`；**MUST NOT** 注入默认用户 prompt、**MUST NOT** 自动 `sendMessage`；聊天区在历史加载完成后 **MUST** 滚动至会话**底部**（或等价展示最新消息），便于接续阅读。
- **子项标题**：展示标题须符合「**xxxx年XX月XX日**的材料」语义；机器可读路由与展示文案映射见 design，展示层须可 i18n。
- **会话归属与单列展示**：该子项内产生的用户消息与助手回复**仅**绑定并展示在该子项页的聊天内容区；**不得**在普通会话列表再增一条用户可感知的并列会话记录。
- **子项页面形态**：子项详情以**类聊天界面**为主；与 `docs/sto-design.md` 对齐。
- **子项未读徽标**：未读 / 已读规则见 design；行尾红点须符合 **Danger / 提醒**语义。

## Capabilities

### New Capabilities

- `home-task-card-subitem-bootstrap`：首页任务卡片点击 → 解析 `taskId`、本地日 `entryId` → **若无子项则创建**并携带「自动发送卡片 prompt」意图导航，**若有则仅**携带「滚底、不发送」意图导航；维护「卡片 → 主任务 → 默认 prompt（仅新建路径消费）」映射。

- `task-subitem-chat-compose-surface`：任务子项以会话为主的详情面；按导航意图分支处理「网关就绪后自动发送一轮」与「仅滚动到底」；与侧栏未读/已读联动；会话范围仅限子项聊天区，**不得**在普通全局会话列表再创建并列项。

### Modified Capabilities

- `home-task-list-surface`：运行时子项集合 + 同日主键复用 + 卡片驱动创建/导航；子项行未读红点与聊天子页同步。

- `dashboard-sto-home-surface`（若仍单独存在）：每张概览卡绑定 `taskId` 与**新建路径**所用默认 prompt 文案（i18n）。

- **会话列表展示**：任务子项内对话**不得**在全局会话列表以第二条并列记录出现。

## Impact

- 预计涉及：`HomeSummaryCards`（或等价入口）、`Sidebar` 子项列表、`TaskDetail` / 子项聊天面、`sto-tasks` 与 store、**滚动容器**与 `loadHistory` 完成后的滚底逻辑、`i18n` 中卡片 prompt 与 `tasks` 子项标题模板。
- 须在 design/spec 中明确**意图字段**（例如 `subitemEntry: 'created' | 'reused'` 或等价），以便子项页区分两条分支。
- 若对外说明路由或行为，审阅三语言 `README*` 是否需一句增量说明。

## Out of Scope

- 真实报表接口、跨设备同步。
- 同日复用路径下仍强制再次自动发送（本 change **禁止**）。
